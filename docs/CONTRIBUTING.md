# Contributing to I-Land1o1

Thank you for your interest in contributing to I-Land1o1.

## Project Vision

I-Land1o1 is a multilingual educational platform that combines modern learning with gamification and exploration.

## Areas for Contribution

- New lessons
- New archipelagos
- UI/UX improvements
- Translations
- Documentation
- Gamification systems
- Accessibility improvements
- Educational content

## Branch Naming

Examples:

feature/new-archipelago
feature/python-course
fix/login-bug
docs/readme-update

## Commit Format

Examples:

feat: add minecraft lesson 3
fix: resolve translation bug
docs: update roadmap
refactor: improve island navigation

## Pull Requests

Please include:

- Description of changes
- Screenshots if UI changes
- Translation updates if needed
- Build verification

## Code Quality

Before submitting:

pnpm run build

Ensure:

- No TypeScript errors
- No build errors
- No broken translations

## Educational Standards

All lessons should follow the course standards defined in COURSE-STANDARDS.md.
