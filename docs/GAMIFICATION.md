# Gamification System

## Philosophy

Learning should feel like an adventure.

Students progress through islands and archipelagos instead of traditional course lists.

---

# XP System

Students earn XP by:

- Completing lessons
- Completing missions
- Passing quizzes
- Maintaining learning streaks

---

# Levels

Level progression unlocks:

- New content
- New islands
- Special rewards

---

# Achievements

Examples:

First Island Completed

First Quiz Passed

100 XP Earned

Programming Explorer

Minecraft Master

Archipelago Conqueror

---

# Rewards

Rewards may include:

- Badges
- Titles
- Cosmetic unlocks
- Certificates

---

# Final Islands

Every archipelago contains a Final Island.

Purpose:

- Final challenge
- Treasure reward
- Certificate
- Parkour challenge
- Archipelago completion

Inspired by legendary end-game destinations in adventure games.
