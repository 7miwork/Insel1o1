# 🏝️ I-Land1o1

一個將教育與遊戲化體驗結合的學習平台，透過群島、任務、成就與探索機制，讓學習成為一場真正的冒險。

## 🌍 線上體驗

🌐 https://7miwork.github.io/I-Land1o1/

---

# 📖 專案願景

I-Land1o1 的目標是將現代教育與遊戲設計理念結合。

學生透過探索群島、完成任務與解鎖內容來學習，而家長、教師與教育機構則擁有專業的管理與分析工具。

平台採用 **雙介面（Dual UI）設計理念**。

# 🗺️ 目前開發中的群島

## 💻 程式設計群島（Programming Archipelago）

I-Land1o1 的第一個學習區域。

### Minecraft Education 方塊程式設計

透過 Minecraft Education Edition 學習程式設計的入門課程。

目前規劃：

| 島嶼 | 內容 |
|--------|--------|
| 島嶼 1 | 課程介紹 |
| 島嶼 2 | 程式基礎 |
| 島嶼 3 | Agent 代理人 |
| 島嶼 4 | 移動控制 |
| 島嶼 5 | 建築與建造 |
| 島嶼 6 | 迴圈（Loops） |
| 島嶼 7 | 條件判斷（Conditions） |
| 島嶼 8 | 事件與聊天指令 |
| 島嶼 9 | 變數（Variables） |
| 島嶼 10 | 最終專案 |
| 島嶼 11 | 最終之島 |

---

# 🏆 最終之島（The Final Island）

Minecraft Education 方塊程式設計群島的傳說終點。

靈感來源：

- 《航海王》Laugh Tale
- 終局內容（Endgame）
- 大師級挑戰

完成所有課程後，學生將可解鎖：

- 最終獎勵
- 特殊成就
- 完課證書
- 傳說寶藏
- 小型跑酷挑戰
- 專屬個人標誌
- 新群島解鎖資格

# 🚀 本地開發

## 複製專案

```bash
git clone https://github.com/7miwork/I-Land1o1.git
cd I-Land1o1
```

## 安裝依賴

```bash
pnpm install
```

## 啟動開發環境

```bash
pnpm run dev
```

## 建立正式版本

```bash
pnpm run build
```

## TypeScript 檢查

```bash
pnpm run check
```
